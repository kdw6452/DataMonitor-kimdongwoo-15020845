# PRD — DataMonitor PoC

> 명령·설정 규칙은 [CLAUDE.md](../CLAUDE.md) 참조.

---

## 1. 배경 및 목적

운영 환경에서 JSON 형태로 저장되는 데이터(설정값, 상태 스냅샷, 이벤트 로그 등)의 현재 상태를
별도의 UI 없이 **콘솔에서 실시간으로** 확인할 수 있는 관리자 도구가 필요하다.

이 PoC는 다음을 증명한다:
- 터미널 단독으로 JSON 데이터를 실시간 모니터링할 수 있다.
- 추후 대시보드·알림 시스템으로 확장 가능한 구조를 갖는다.

---

## 2. 대상 사용자

| 사용자 | 역할 | 주요 니즈 |
|---|---|---|
| 시스템 관리자 | 운영 데이터 상태 점검 | 빠른 이상 탐지, 키·값 변화 추적 |
| 개발자 | 로컬 디버깅 | 특정 필드 필터링, 변경 diff 확인 |

---

## 3. 목표 (Goals)

1. JSON 파일(또는 디렉터리)을 지정된 주기로 폴링하여 콘솔에 현재 상태를 표시한다.
2. 직전 상태와 비교해 **변경된 필드를 강조**한다.
3. 키워드 기반 **필터링** 기능을 제공한다.
4. 별도 설치 없이 `pip install` 후 즉시 실행 가능하다.

## 4. 비목표 (Non-Goals)

- 웹 UI / GUI 대시보드
- 데이터베이스 직접 연동
- 알림(슬랙·이메일) 전송 — PoC 범위 초과

---

## 5. 핵심 기능 요구사항

### F-01. 데이터 로드
- 단일 JSON 파일 또는 디렉터리 내 복수 JSON 파일을 소스로 지정할 수 있다.
- 파일이 유효하지 않은 JSON일 경우 오류 메시지를 표시하되 모니터링은 중단하지 않는다.

### F-02. 실시간 갱신
- 기본 폴링 간격: 2초 (CLI 옵션으로 조정 가능).
- 변경 감지 시 화면을 즉시 갱신한다.

### F-03. 변경 하이라이트
- 추가된 키: 초록색
- 삭제된 키: 빨간색
- 값이 변경된 키: 노란색
- 변경 없는 키: 기본 색상

### F-04. 필터링
- 특정 키 경로 또는 값 패턴으로 표시 범위를 좁힐 수 있다 (예: `--filter status`).

### F-05. 콘솔 UI
- 터미널 전체를 채우는 인터랙티브 레이아웃.
- 헤더: 파일 경로, 마지막 갱신 시각, 폴링 간격.
- 바디: JSON 트리 또는 플랫 키-값 목록.
- 푸터: 단축키 안내 (`q` 종료, `r` 수동 새로고침, `f` 필터 입력).

### F-06. CLI 인터페이스

```
python -m datamonitor [OPTIONS]

Options:
  --data-path PATH     JSON 파일 또는 디렉터리 경로  [기본: ./data]
  --interval SECONDS   폴링 간격 (초)               [기본: 2]
  --filter PATTERN     키 또는 값 필터 패턴
  --flat               중첩 JSON을 플랫 키-값으로 표시
  --no-color           색상 출력 비활성화
```

## 6. 비기능 요구사항

| 항목 | 요구사항 |
|---|---|
| 성능 | 단일 JSON 파일 1 MB 이하에서 갱신 지연 < 500 ms |

## 7. 성공 지표 (PoC 기준)

- [ ] 로컬 JSON 파일 실시간 갱신이 육안으로 확인 가능
- [ ] 변경 하이라이트가 정확히 동작
- [ ] `q` 키로 깔끔하게 종료
- [ ] 기본 테스트 커버리지 ≥ 70 %
